# 應許之地 (Promise Land) — 隱私權政策與技術支援 (Privacy Policy & Support)

最後更新日期：2026 年 11 月 12 日

感謝您使用「應許之地 (Promise Land)」（以下簡稱「本應用程式」）。我們非常重視您的隱私權，本隱私權政策說明本應用程式如何處理您的資訊。

## 1. 個人資料的收集與使用
- **免註冊與零個資收集**：本應用程式無須註冊帳號即可使用。我們**不會**收集、儲存或分享您的姓名、電子郵件、電話、位置或任何可識別個人身分的資料（PII）。
- **心情文字處理**：當您在應用程式中輸入心情或處境文字以獲取聖經經文推薦時，該段文字僅會透過加密連線（HTTPS）即時傳送至 Google Gemini API 進行經文與回應生成，本應用程式伺服器不會留存您的輸入紀錄。

## 2. 第三方服務
本應用程式使用 Google 提供的生成式 AI 服務（Gemini API）協助產生經文回應，傳輸過程全程使用標準 HTTPS 加密保護。

## 3. 資料安全與兒童隱私
本應用程式不包含任何廣告追蹤 SDK，亦不收集任何年齡層（包含兒童）的個人資料。
